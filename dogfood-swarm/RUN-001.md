## The loop (as built)

```
GRAPH:  claims(claim:c-001, verdict=0, claimant=lucidota)
          → needs_evidence → task:ev-001 (pending)
EXCHANGE: POST /v1/job {capability:cognitive, input:{task_type:execute-verify,
          graph_task_id, claim_id, execution:{model,prompt}, expect:{match,value}}}
          → gates (EVIDENCE requires AVAILABLE — earned, not granted)
          → lease + deferred (the Exchange IS the queue)
WORKER:   swarm-claimant-01: /v1/claim → delegation (atomic)
          → subprocess swarm-worker.py → NIM executes probe
          → deterministic check(output, expect) → ternary verdict
          → /v1/complete {worker_outcome:SUCCEEDED,
                          output:{ternary_verdict, check, graph_task_id}}
EXCHANGE: receipt binds claim_id + worker_outcome + output (D1, queryable)
GRAPH:    verifies(task → claim, verdict=±1,
            claimant=worker:swarm-claimant-01, receipt_id=<receipt>)
```

## Architecture correction compliance

1. **No daemon.** Nothing watches `graph-drops/`. The claimant pulls via
   `/v1/claim`; the governor's deferred-delegation queue is the work queue.
2. **No determinism theater.** The model executed prompts; `deterministic_check`
   (exact/contains/hash-sha256/nonempty) produced every verdict. The model was
   never asked for an opinion. Swapping in canned text leaves verdict logic unchanged.
3. **NIM as validator.** Both probes ran against `openai/gpt-oss-20b` via the
   vault-held credential (nvidia-nim skill surrogate — secret never travels).
4. **Graph-native.** Task nodes + `needs_evidence` + `verifies` edges in exact
   `lifelog_edge` DDL schema (`graph-drops/`), receipt-bound, append-only.

## Bugs found and fixed during the run

1. **Gauntlet branch returned a dict as exit code** — `return execute_verify(...)`
   instead of printing it; Python printed the repr to stderr, exit 1.
   Fixed: print + return 0.
2. **Reasoning-model prompt fragility** — "Reply with exactly: ok" produced
   reasoning leakage, failing `exact`. Added `nonempty` match type for
   gauntlet-grade probes (verifies the validator drives NIM, not model behavior).
3. **Model stochasticity** — same prompt gave '4' once, non-"4" output the next
   run at temperature 0.0. Honest consequence: single probes can misfire; the
   graph accumulates verdicts rather than trusting one.
